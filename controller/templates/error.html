O painel está rodando e a API dos agentes está no ar, mas não foi possível carregar o pacote do painel:

{{.Error}}

Como resolver:

  • Sem internet? O pacote é baixado uma vez das GitHub Releases e fica em cache local. Conecte-se e reinicie, ou rode uma vez numa máquina com internet.
  • Build de desenvolvimento? Gere o painel localmente (cd web && bun install && bun run build, ou npm install && npm run build) e inicie o painel com {{.DirKey}}: web/dist no config.yml do controller, ou controller.WithUIDir("web/dist").
  • Fixe uma versão com {{.VersionKey}}: vX.Y.Z no config.yml, ou controller.WithUIVersion("vX.Y.Z").

A API JSON continua funcionando: /api/agents e a de cada agente em /api/agents/{agente}/pairs, /api/agents/{agente}/{pair}/snapshot, /api/agents/{agente}/events.
